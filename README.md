# 今日、講義ある？（講義日チェック）

自分の時間割と、取り込んだ大学の年間行事予定（PDF・画像・JSON）を照合し、選択した日に講義があるか確認するWebアプリです。行事予定のデータはアプリに内蔵しておらず、利用者が取り込んだものだけを使います。

## 使い方

1. `index.html` をブラウザーで開きます。
2. 「行事予定を取り込む」で、年間行事予定のPDF・画像・JSONを読み込みます（初回は必須です。取り込むまで判定はできません）。
3. 「自分の時間割を登録」で、普段講義がある曜日の時限にチェックを入れ、「時間割を保存」を押します。時間割は利用中のブラウザーの `localStorage` に保存されます。
4. 日付を選び、「講義があるか判定する」を押すと結果が表示されます。

## ファイル構成

- `index.html`：画面の構造
- `style.css`：デザインとスマートフォン対応
- `script.js`：時間割の保存、日付判定、取り込んだ行事予定の反映
- `material.css`：Material You風のテーマ（色・角丸・ボタン・ボトムバーの見た目）。`style.css` のあとに読み込み、見た目だけを上書きします。不要なら index.html の `<link>` を削除してください
- `nav.js`：スマホ（幅760px以下）のボトムバーによる画面（判定／時間割／行事予定）の切り替え
- `calendar-parser.js`：行事予定PDF（カレンダー表）のテキスト項目 → JSON変換
- `calendar-import.js`：PDF取り込み、確認・修正画面、JSONの書き出し／読み込み

## 画面の構成

- 幅761px以上（PC・タブレット）：3つのパネルを並べて表示します。
- 幅760px以下（スマホ）：画面下のボトムバー（判定／時間割／行事予定）で、表示するパネルを切り替えます。HTMLは1枚のままで、`data-view` を持つパネルの表示・非表示を切り替えています。最後に開いていた画面は、ブラウザーを閉じるまで覚えています。
- ダークモード：端末の設定に合わせて自動で切り替わります（`material.css` の `prefers-color-scheme: dark` の部分）。

## 行事予定の取り込み（PDF → JSON）

画面下部の「行事予定を取り込む」から、大学の年間行事予定PDFを読み取れます。

1. PDFを選び、「読み取る」を押します（年度は空欄で自動判定。判定できないときだけ入力してください）。
2. 表示された一覧で、種類（授業日／試験／行事・休日）・授業回数・行事名を確認し、必要なら修正します。
3. 「このカレンダーを使う」で保存すると、判定がその年度のデータに切り替わります（ブラウザーの `localStorage` に保存）。
4. 「現在のデータをJSONで書き出す」で保存でき、あとでJSONを読み込み直せます。「取り込んだデータを削除」で、取り込んだ行事予定を消せます（時間割は消えません）。

- 読み取りはブラウザー内で行われ、PDFは外部に送信されません（PDF読み取りライブラリ pdf.js、画像用のOCRライブラリ Tesseract.js と日本語データのみ、初回にCDNから読み込みます）。
- 対応しているのは、週表示（月〜日の列）のカレンダー表です。PDFはテキストが埋め込まれたもの、画像はPNG/JPEG（スクリーンショット）を想定しています。
- 画像はブラウザー内のOCR（Tesseract.js・日本語）で読み取ります。初回は日本語データのダウンロードに時間がかかります。丸数字（①〜⑮）や行事名は読み違えやすいため、確認画面での見直しが前提です。文字が小さい・ぼやけた画像は精度が下がるので、できるだけ大きく鮮明な画像を使ってください。
- スキャンしただけのPDF（文字が埋め込まれていないもの）は、画像として保存してから取り込んでください。
- 年度はPDF中の「（2023年度）」などの表記から判定し、4月1日の曜日が表の配置と合うかで検証します。合わない場合は読み込みを止めます。
- 折り返された行事名や、複数の行事が並ぶセルの区切りは推測です。必ず確認画面で見直してください。

### JSONの形式

```json
{
  "meta": { "academicYear": 2023, "startDate": "2023-04-01", "endDate": "2024-03-31" },
  "days": {
    "2023-04-06": { "type": "event", "label": "入学式" },
    "2023-04-12": { "type": "lecture", "session": 1 },
    "2023-08-01": { "type": "exam" }
  }
}
```

`type` は `lecture`（授業日）／`exam`（期末試験）／`event`（行事・休日）。`session` はPDFの①〜⑮（授業回数）です。

## 日程データについて

行事予定は、取り込んだPDF・画像・JSONの内容だけを使います（アプリには内蔵していません）。読み取り結果は保存前に確認・修正できますが、すべての休講・補講・個別科目の予定を網羅するものではありません。必ず大学の最新案内を確認してください。判定できる期間は、取り込んだ年度（4月1日〜翌年3月31日）です。次年度は、その年度のPDFを取り込んでください。

## 判定ロジックの注意

- 大学行事予定上の授業実施日と、利用者が登録した曜日の時間割を照合します。
- 期末試験日は通常授業とは分けて「期末試験期間」と表示します。
- 大学祭・祝日・入試など、登録された行事がある日は注意表示を出します。
- このアプリは授業日確認を補助するもので、休講・補講・試験の正式な案内に代わるものではありません。

## 使用技術

HTML / CSS / JavaScript / localStorage（外部ライブラリ不要）
